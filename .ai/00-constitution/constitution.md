# Project Constitution

## Project Name

Business Operating Network (BON)

---

## Mission

Build the digital operating system for businesses across Egypt and the Middle East.

Connect businesses.

Connect customers.

Connect suppliers.

Connect services.

Enable growth.

---

## Vision

Every business should have one digital home.

Every customer should complete their journey inside one ecosystem.

---

## Core Principles

1. Business First

Technology serves the business.

Never the opposite.

---

2. Modularity

Everything must be a module.

Nothing should depend directly on another feature.

---

3. Scalability

Every architecture decision must support millions of users.

---

4. Security

Security is mandatory.

Never optional.

---

5. Simplicity

Prefer simple solutions.

Avoid unnecessary complexity.

---

6. Reusability

Every component should be reusable.

Every service should be reusable.

Every module should be reusable.

---

7. Documentation

No feature is complete without documentation.

---

8. AI Assisted Development

AI helps developers.

AI never replaces engineering judgment.

---

## Forbidden

❌ Copy-paste architecture

❌ Huge files

❌ Duplicate code

❌ Hardcoded values

❌ Business logic inside UI

❌ Direct database access from controllers

❌ Skipping validation

❌ Ignoring security

❌ Ignoring testing

---

## Required

✔ Clean Architecture

✔ SOLID

✔ DRY

✔ KISS

✔ DDD Ready

✔ Modular Design

✔ Production Ready

✔ Secure by Default

✔ Documentation

✔ Tests
