These industries must remain compatible with the architecture.

However:

Never optimize early development around them.

Do not build restaurant-specific features.

Do not build clothing-specific features.

Instead create generic modules that every industry can reuse.

-------------------------------------

Business Rule

Never build features for one industry.

Always build platforms.

Cars should use Inventory.

Factories should use Inventory.

Agriculture should use Inventory.

Construction should use Inventory.

One module.

Many industries.
