# الكاشير (RayCashier) — تطبيق كاشير أوفلاين

تطبيق كاشير سطح مكتب (Windows) مبني بـ **Go + Wails v2 + SQLite** — بيشتغل **بدون نت** بالكامل، وبيتزامن تلقائيًا مع `gobackend` أول ما النت يرجع. شكله وسلوكه نسخة مطابقة لصفحة POS في الداشبورد (`apps/dashboard-web/app/dashboard/(main)/pos/`).

## التشغيل

الملف الجاهز: `build/bin/RayCashier.exe` — افتحه على جهاز الكاشير.

1. **شاشة الربط (مرة واحدة بس):** رابط السيرفر (مثل `http://localhost:4000` أو رابط السيرفر السحابي) + إيميل التاجر وكلمة السر. بيجيب المحل والمنتجات وإعدادات الكاشير ويخزنها محليًا. **للأمان: بعد 90 يوم من آخر تأكيد التطبيق يطلب إعادة تأكيد حساب التاجر (نفس الشاشة) — البيانات والفواتير المحلية مش بتتلمس وبتتزامن بعد التأكيد. ولو انتهت الجلسة على السيرفر في أي وقت بيرجع لنفس الشاشة.**
2. **بطاقة الدخول:** زي الداشبورد بالظبط:
   - وردية جديدة: العهدة الافتتاحية + اسم الكاشير + رقمه السري → الورديّة تتسجل.
   - وردية مفتوحة: اسم الكاشير + رقمه السري → استكمال.
   - **الأدمن:** يكتب رقم سري الأدمن (من خانة "دخول أدمن") فيفتح بكل الصلاحيات (تقرير X، إغلاق وردية Z، حركات الكاش).
3. **البيع:** بحث (F2) / تصنيفات / تعليق (F6) / باركود USB — نفس شاشة POS. الدفع كاش/بطاقة/محفظة/آجل + خصم. كل فاتورة تتسجل محليًا **فورًا** وتتطبع 80mm.

## المزامنة (زي النظام الموجود)

- البيع أولًا في SQLite محلي (UUID + `synced=0`) — **صفر انتظار للنت وصفر فقدان فواتير**.
- Worker كل 20 ثانية (ووقت كل عملية بيع) لما السيرفر متاح:
  - **Pull:** المنتجات (`GET /api/v1/products?shopId=`) + إعدادات الكاشير من `layoutConfig.posSettings` (الأرقام السرية والصلاحيات زي الداشبورد).
  - **Push:** الفواتير المعلقة (`POST /shops/:id/orders` بنفس شكل payload الـ POS: `source: 'pos'`, `COD|CARD|WALLET|CREDIT`, الخصم في `notes`) + فتح/إغلاق الورديات (`/shops/:id/shifts`...).
- الـ idempotency عبر UUID: نفس الفاتورة متتسجلش مرتين.
- الأرقام السرية (PINs) مصدرها السيرفر زي الداشبورد — مفيش PIN منفصل للتطبيق.

## قاعدة البيانات المحلية

`%APPDATA%\ray-cashier\cashier.db` — جداول: `products`, `orders`, `order_items`, `pos_shifts` (نفس أعمدة جدول السيرفر), `cash_movements`, `held_orders`, `settings`.

## التطوير

```bash
cd apps/cashier-desktop
wails build        # ينتج build/bin/RayCashier.exe
wails dev          # تطوير حي (hot reload)
```

لو الشبكة بتقطّع أثناء `go mod tidy`: `GOPROXY=https://goproxy.cn,direct GOSUMDB=off`.

## النشر (توزيعه للتاجر كتطبيق حقيقي)

البناء المحلي لملف تثبيت:

```bash
# NSIS مطلوب (choco install nsis أو نزّله portable)
wails build -nsis
# الناتج: build/bin/RayCashier-amd64-installer.exe (~8MB)
```

التاجر بيثبته زي أي برنامج: Next → Next → يفتح الكاشير، بيظهر في قايمة Start
واختصار على الديسكوب، وبيتمسح من "Add/Remove Programs".

**النشر أوتوماتيك** (زي تطبيق الإلكترون): workflow جاهز في
`.github/workflows/cashier-release.yml` — أول ما تعمل tag:

```bash
git tag cashier-v1.0.0
git push origin cashier-v1.0.0
```

GitHub Actions يبني الـ installer وينشره على:
`https://github.com/Sayedtaha55/ray-eg/releases/latest` — ولينك التحميل الثابت للتاجر.

**تحديث النسخة**: عدّل `productVersion` في `wails.json` → اعمل tag جديد.
(Wails v2 مفيهوش auto-update جاهز زي electron-updater — نقدر نضيف فحص إصدار بسيط بعدين).

## ملاحظات

- الحسابات المزامة بتعتمد إن جهاز الكاشير عمل login مرة واحدة — لو انتهت الجلسة بيحصل refresh تلقائي، ولو فشل هيظهر تنبيه إعادة ربط.
- حركات الكاش (إيداع/سحب) محلية زي الداشبورد (السيرفر ملهاش endpoint) — وبتظهر في تقرير X.
- المرتجعات والإعدادات المتقدمة (أرصفة/تقسيط...) لسه في الداشبورد — مش في نسخة الكاشير v1.
